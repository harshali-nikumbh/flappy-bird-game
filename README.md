# Flappy Bird Game Clone

A Flappy Bird-inspired arcade game built using Python and Pygame.

## Features

- Smooth bird movement
- Obstacle generation
- Collision detection
- Score tracking
- Sound effects
- Game over screen

## Tech Stack

- Python
- Pygame

## Installation

1. Clone the repository

```bash
git clone https://github.com/harshali-nikumbh/flappy-bird-game.git
```

2. Install dependencies

```bash
pip install pygame
```

3. Run the game

```bash
python flappybird.py
```
